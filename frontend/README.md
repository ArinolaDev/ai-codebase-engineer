# Frontend

Plain HTML, CSS and JavaScript. No build step and nothing to install.
The FastAPI backend serves this folder at http://127.0.0.1:8000/ui/ (and redirects `/` there).

- `index.html` page shell
- `css/app.css` design tokens and components
- `js/app.js` shell and router, `home.js`, `overview.js`, `findings.js`, `fix.js` (fix workspace),
  `diff.js` (diff viewer and verdict), `tests.js`, `graph.js`, `chat.js`, `codeview.js`, `util.js`
